# XPAY 支付中台

当前阶段只实现后台基础框架和 UI，不包含任何真实支付、下单、回调、余额、提现、代付或资金清算功能。

## 已实现

- 后台登录页占位
- 后台主布局：左侧菜单、顶部导航、主内容区、面包屑、管理员信息、退出入口占位
- 控制台首页：指标卡片、最近订单模拟表格、系统状态模拟卡片
- 占位页面：订单管理、回调日志、支付日志、商户管理、支付通道、支付方式、系统设置、管理员管理

## 启动方式

这是纯静态页面，可以直接用浏览器打开：

```text
C:\Users\Administrator\Desktop\XPAY\index.html
```

也可以在项目目录启动本地静态服务：

```powershell
python -m http.server 5173
```

然后访问：

```text
http://localhost:5173
```

## 测试方式

1. 打开 `index.html` 或访问本地静态服务。
2. 在登录占位页点击“进入后台演示”。
3. 检查控制台指标卡片、最近订单表格、系统状态卡片是否正常显示。
4. 点击左侧菜单，确认所有占位页面都有标题、卡片布局和空数据提示。
5. 点击顶部“退出登录”，确认回到登录占位页。
